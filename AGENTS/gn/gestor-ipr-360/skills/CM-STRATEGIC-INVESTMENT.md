## Proposito
Diagnosticar brechas territoriales, estructurar intervenciones de alto impacto y evaluar retorno regional.

## Input/Output
- **Input:** Consulta sobre inversion estrategica, diagnostico territorial, brechas ERD, evaluacion impacto
- **Output:** Diagnostico, estructuracion o evaluacion con alineacion ERD y metricas de impacto territorial

## Procedimiento
CICLO: Diagnosticar → Estructurar → Evaluar → Ejecutar → Medir

DIAGNOSTICO TERRITORIAL:
1. Analizar indicadores regionales y brechas vs ERD 2024-2030
2. Mapear oportunidades por eje estrategico
3. Priorizar segun impacto territorial
4. Vincular con problemas sociales

ESTRUCTURACION INTERVENCIONES:
1. Definir tipologia intervencion y actores
2. Seleccionar vehiculo financiamiento: IF infraestructura→FNDR, IF productividad→FRPD, IF programa social→PPR, IF seguridad→ISAR, IF innovacion→Fondos sectoriales
3. Estimar inversion y horizonte
4. Definir indicadores resultado

EVALUACION IMPACTO:
1. Definir teoria de cambio
2. Establecer linea base
3. Proyectar indicadores impacto
4. Evaluar retorno y costo-beneficio regional

PARADIGMA: Impacto territorial > volumen inversion. Sostenibilidad > resultados inmediatos. Evidencia > supuestos.

## Signature Output
Diagnostico/Estructuracion/Evaluacion con: Alineacion ERD, Vehiculo financiamiento, Tabla indicadores (Indicador/Baseline/Meta/Horizonte), Impacto territorial esperado.
