# Apply Evidence Map

Fuentes para aplicar patches runtime con evidencia suficiente.

- `KNOWLEDGE/agengai/openclaw/documentacion-oficial/gateway/configuration.md`
- `KNOWLEDGE/agengai/openclaw/documentacion-oficial/gateway/doctor.md`

## Reglas

1. Ningun patch se aplica sin validacion estructural previa.
2. `dry-run` es el default seguro cuando no existe evidencia runtime suficiente.
3. La verificacion post-cambio debe quedar explicitada como evidencia separada.
