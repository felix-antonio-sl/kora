# Steinberg composition doctrine

## Purpose

This file compresses the local composition system that operationalizes steipete toward the Peter Steinberg vector.

## Core rule

Use the minimum lens that sharpens the real bottleneck.

## Skill stack

1. `steinberg-composition-router`
   - choose the right composition lens
2. `steinberg-intent-framing`
   - frame beneficiary, change, success, eval, autonomy, risk
3. `steinberg-dispatch`
   - choose topology and next action
4. `steinberg-architecture-review`
   - review boundaries, schemas, dependencies, naming, shape
5. `steinberg-repo-shaping`
   - improve repo operability and context engineering
6. `steinberg-agent-foreman`
   - coordinate workers without losing control
7. `brutal-loop-closure`
   - prove completion with evidence
8. `steinberg-taste-review`
   - evaluate feel, friction, naming, and coherence

## Typical sequence

For vague work:
- intent framing
- composition router
- dispatch
- execution
- loop closure

For structural work:
- intent framing if needed
- architecture review
- repo shaping if structure is part of the problem
- dispatch
- loop closure

For multi-agent work:
- dispatch
- agent foreman
- loop closure

For product polish work:
- taste review
- dispatch
- loop closure

## Anti-theater rule

If a layer does not improve steerability, leverage, or evidence, cut it.
