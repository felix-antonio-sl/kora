# 2026-04-07 — Sesión hdos-app (MVP)

## Contexto
- Proyecto: hdos-app (/home/felix/projects/hdos-app)
- Stack: Next.js 16 + Drizzle ORM + Tailwind CSS 4 + TypeScript + PWA
- BD: PostgreSQL hodom-pg-v4, puerto 5555, 103 tablas en 8 schemas
- Hosting: hd.sanixai.com
- Colaboración: steipete + Fugaz (agentId: fugaz) en el mismo repo
- Node: v22 (upgrade desde v18)

## Decisiones arquitectónicas
- **BD existente** — no se crea schema nuevo; app conecta directamente a hodom-pg-v4
- **Query helpers** — `query<T>` y `queryOne<T>` en `src/db/query.ts` usando drizzle `sql` template tag. Convención: **nunca usar raw SQL strings**, siempre `sql\`...\``
- **Auth MVP** — login por nombre contra `operational.profesional` (sin password, red cerrada). JWT en cookie httpOnly. API routes: `/api/auth/login`, `/api/auth/logout`
- **Portal paciente** — auth separada: email/password + single-use invite codes, en `/portal/*`
- **Colaboración** — steipete: censo/ficha/llamadas/rem/agenda/profesionales; Fugaz: admisión/egreso/portal
