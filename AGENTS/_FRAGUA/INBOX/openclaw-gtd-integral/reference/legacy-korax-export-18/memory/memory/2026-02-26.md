## Lección técnica: OAuth en VPS

- `gog auth add` levanta servidor local en puerto aleatorio esperando callback
- El callback de Google apunta a 127.0.0.1:<puerto> del VPS → el usuario no puede completar el flow directamente
- Solución: túnel SSH `ssh -L <puerto>:127.0.0.1:<puerto> clawdbot@100.99.32.96`
- Luego usuario abre URL OAuth en su browser → callback viaja por el túnel al VPS
- El proceso debe correr en tmux (no exec directo) para no morir por timeout
