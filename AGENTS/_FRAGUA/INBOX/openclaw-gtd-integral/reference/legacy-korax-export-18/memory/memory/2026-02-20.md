## qwen-plus: Bug identificado y decisión tomada

**Problema:** Qwen3.5 Plus (`dashscope/qwen-plus`) en modo conversacional expone su reasoning chain interno como texto visible al usuario. El modelo genera pensamiento extendido antes de responder y todo eso aparece en la respuesta final.

**Causa técnica:** `enable_thinking` activo por defecto en Qwen3.5 Plus cuando se usa con DashScope API.

**Fix teórico:** Pasar `extra_body: {enable_thinking: False}` en la llamada. Esto es un parámetro fuera del estándar OpenAI, se inyecta como `extra_body` en el SDK. **No confirmado cómo hacer esto vía openclaw.json.**

**Decisión:** Mover qwen-plus a alias-only. No usar en fallback automático hasta resolver thinking mode o confirmar mecanismo OpenClaw.

**Cadena propuesta corregida (no aplicada aún):**
```
sonnet → minimax → kimi → glm-flash → deepseek → glm-5 → opus
```
(qwen-plus queda como alias manual para contextos >200K)
