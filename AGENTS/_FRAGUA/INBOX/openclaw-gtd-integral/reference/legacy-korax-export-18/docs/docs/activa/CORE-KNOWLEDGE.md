## LOS 7 DOMINIOS FUNDAMENTALES

### I. ESTRUCTURA (Matemática)
*El lenguaje de los patrones*

- Lógica
- Conjuntos y relaciones  
- Categorías y composición
- Topología
- Grafos

### II. INFORMACIÓN (Física del conocimiento)
*Qué se puede saber y transmitir*

- Entropía
- Complejidad
- Límites
- Emergencia

### III. MENTE (Cognición)
*El sustrato que extendemos*

- Conciencia
- Representación
- Razonamiento
- Límites cognitivos
- Neurociencia

### IV. LENGUAJE (Significado)
*El puente entre mentes*

- Semántica
- Pragmática
- Comunicación
- Formalización

### V. SISTEMAS (Organización)
*Cómo las partes forman todos*

- Composición
- Feedback
- Resiliencia
- Colapso

### VI. EVOLUCIÓN (Cambio)
*Cómo se transforma lo que existe*

- Selección
- Adaptación
- Coevolución
- Dinámica exponencial
- Singularidades

### VII. ÉTICA (Valor)
*Qué debe hacerse*

- Responsabilidad
- Autonomía
- Justicia
- Límites
- Precaución

## MAPA DETALLADO POR DOMINIO

### I. ESTRUCTURA

| Tópico | Esencia |
|--------|---------|
| Lógica formal | Reglas del razonamiento válido |
| Teoría de conjuntos | Colecciones y pertenencia |
| Relaciones | Conexiones entre objetos |
| Teoría de categorías | Composición universal |
| Álgebra | Estructuras y operaciones |
| Topología | Continuidad y forma |
| Teoría de grafos | Redes y conexiones |

### II. INFORMACIÓN

| Tópico | Esencia |
|--------|---------|
| Entropía | Medida de incertidumbre |
| Complejidad algorítmica | Información mínima para describir |
| Complejidad computacional | Recursos para calcular |
| Límites de computabilidad | Qué no se puede calcular |
| Sistemas complejos | Muchas partes, comportamiento emergente |
| Auto-organización | Orden sin diseñador |
| Caos | Sensibilidad a condiciones iniciales |

### III. MENTE

| Tópico | Esencia |
|--------|---------|
| Problema mente-cuerpo | Relación cerebro-experiencia |
| Conciencia | Experiencia subjetiva |
| Intencionalidad | Mente "sobre" algo |
| Representación mental | Cómo modelamos el mundo internamente |
| Funcionalismo | Mente como función, no sustancia |
| Mente extendida | Cognición más allá del cráneo |
| Arquitectura cerebral | Organización funcional |
| Memoria | Almacenamiento y recuperación |
| Atención | Selección y foco |
| Plasticidad | Cambio estructural por experiencia |
| Heurísticas | Atajos cognitivos |
| Sesgos | Errores sistemáticos |
| Metacognición | Pensar sobre el pensar |

### IV. LENGUAJE

| Tópico | Esencia |
|--------|---------|
| Semántica | Significado de expresiones |
| Referencia | Cómo los símbolos apuntan al mundo |
| Pragmática | Significado en contexto |
| Actos de habla | Lenguaje como acción |
| Significado como uso | Wittgenstein tardío |
| Lenguaje y pensamiento | ¿Pensamos en palabras? |
| Lenguajes formales | Sintaxis y semántica precisas |
| Ground truth | Anclaje del significado |

### V. SISTEMAS

| Tópico | Esencia |
|--------|---------|
| Composición | Partes → todos |
| Modularidad | Independencia de componentes |
| Acoplamiento | Dependencias entre partes |
| Feedback | Ciclos de retroalimentación |
| Homeostasis | Estabilidad dinámica |
| Jerarquía | Niveles de organización |
| Resiliencia | Absorber perturbaciones |
| Antifragilidad | Mejorar con estrés |
| Colapso | Falla sistémica |
| Transiciones de fase | Cambios cualitativos abruptos |

### VI. EVOLUCIÓN

| Tópico | Esencia |
|--------|---------|
| Selección natural | Supervivencia diferencial |
| Fitness | Adaptación al entorno |
| Variación | Fuente de novedad |
| Herencia | Transmisión de información |
| Evolución cultural | Ideas como replicadores |
| Coevolución | Cambio mutuo de sistemas acoplados |
| Path-dependence | La historia importa |
| Exaptación | Funciones emergentes no diseñadas |
| Crecimiento exponencial | Duplicación constante |
| Curvas S | Crecimiento → saturación |
| Singularidades | Puntos de discontinuidad |
| Escenarios | Futuros posibles |

### VII. ÉTICA

| Tópico | Esencia |
|--------|---------|
| Consecuencialismo | Juzgar por resultados |
| Deontología | Juzgar por reglas/deberes |
| Ética de virtudes | Juzgar por carácter |
| Responsabilidad | Quién responde |
| Agencia moral | Quién puede ser juzgado |
| Autonomía | Derecho a decidir |
| Paternalismo | Decidir por otros "por su bien" |
| Justicia | Distribución justa |
| Transparencia | Poder ser auditado |
| Explicabilidad | Poder ser entendido |
| Precaución | Actuar ante incertidumbre |
| Reversibilidad | Poder corregir |
| Límites | Qué NO debe hacerse |
| Alineamiento | Que el sistema haga lo que queremos |
| Riesgo existencial | Amenazas a la humanidad |
