# Medicina de Urgencia: Principios y Métodos

*Reconstrucción desde cero - 2026-02-25*

---

## 1. Fundamento: El Factor Tiempo

La medicina de urgencia se define por **el factor tiempo** como criterio definitorio. La respuesta oportuna es la diferencia entre vida y muerte, entre secuela permanente y recuperación completa.

> "El tiempo es cerebro" (ictus)  
> "El tiempo es músculo" (IAM)  
> "La golden hour" (trauma)

---

## 2. Principios Fundamentales

### 2.1. Principio de Priorización (ABCDE)

**Orden jerárquico de atención basado en amenaza vital:**

| Letra | Significado | Acción |
|-------|-------------|--------|
| **A** | Airway (Vía aérea) |确保 permeabilidad + cervical |
| **B** | Breathing (Respiración) | Oxigenación, ventilación |
| **C** | Circulation (Circulación) | Flujo, hemorragia, RCP |
| **D** | Disability (Discapacidad) | Neurológico, Glasgow |
| **E** | Exposure (Exposición) | Temperatura, exposición completa |

**Regla de oro:** Nunca avanzar al siguiente paso sin haber resuelto el anterior.

### 2.2. Principio de Detección y Tratamiento Simultáneos

ATLS (Advanced Trauma Life Support):
> "Evaluar condición del paciente con rapidez y precisión. Reanimar y estabilizar según prioridad."

No es secuencial (evaluar → tratar), es **simultáneo**.

### 2.3. Principio de la Mejor Evidencia Disponible

Protocolos basados en:
- Ensayos clínicos aleatorizados
- Consensos de expertos (ILCOR, AHA, ATLS)
- Guías de práctica clínica

### 2.4. Principio de Seguridad del Paciente

- Verificación sistemática (checklist)
- Identificación de errores potenciales
- Redundancia en pasos críticos

## 3. Arquitectura del Sistema de Urgencias

### 3.1. Cadena de Supervivencia

```
1. Detección → 2. Activación → 3. Respuesta prehospitalaria → 4. Transporte → 5. Atención hospitalaria
```

### 3.2. Componentes del Sistema Integral de Urgencias

| Componente | Función |
|------------|---------|
| **Prehospitalario** | SAMU, rescate, primeros respondedores |
| **Hospitalario** | Emergency department, UCI |
| **Transporte** | Ambulancia, aeroevacuación |
| **Comunicación** | Centro coordinador, telecomando |

## 4. Métodos de la Medicina de Urgencia

### 4.1. Triage

**Definición:** Proceso de clasificación de pacientes según la gravedad para priorizar atención.

**Esquemas de triage:**

| Sistema | Categorías | Criterio |
|---------|------------|----------|
| **START** (mass casualty) | Rojo / Amarillo / Verde / Negro | Walk, breathe, respirations, perfusion |
| **ESI** (hospitalario) | 1-5 | Recursos necesarios + vital signs |
| **Manchester** | 5 colores | Motivo consulta + signos vitales |

**Código rojo (inmediato):** Shock, Glasgow ≤8, sangrado activo → **amenaza vital inmediata**

### 4.2. Primary Survey (Evaluación Primaria)

**Objetivo:** Identificar y corregir amenazas vitales inmediatas.

**Secuencia ABCDE:**
1. **A - Vía aérea con protección cervical**
   - Maniobra jaw-thrust
   - C-collar si trauma
   - Airway definitivo si necesario (intubación)

2. **B - Respiración y ventilación**
   - Oxígeno suplementario
   - Identificar neumotórax, hemotórax
   - Ventilación si requiere

3. **C - Circulación y control de hemorragia**
   - 2 vías venosas periféricas amplias
   - Resucitación con cristaloides
   - Control de hemorragia externa
   - Considerar sangre temprana

4. **D - Discapacidad neurológica**
   - Escala de Glasgow
   - Pupilas
   - Signos de focalización

5. **E - Exposición y control ambiental**
   - Desvestir completamente
   - Prevenir hipotermia

### 4.3. Secondary Survey (Evaluación Secundaria)

**Objetivo:** Evaluación sistemática head-to-toe tras estabilización.

- Anamnesis: AMPLE (Alergias, Medicamentos, Patologías previas, Last meal, Eventos)
- Examen físico completo
- Exámenes complementarios dirigidos

### 4.4. Reanimación

**Principles:**
- **Hemorragia control primero** → luego fluidos
- **Permisiva hipotensión** en trauma penetrante (hasta 80-90 mmHg)
- **1:1:1** ratio sangre:plasma:plaquetas en transfusión masiva
- **Calcium** en transfusión masiva (hipocalcemia)

### 4.5. Decisión de Transporte

- "Transport immediate to appropriate + close center, preferably verified trauma center"
- Minimizar tiempo en escena
- Elegir centro según capacidad

## 5. Síntesis: Algoritmo Universal

```
Paciente urgente
       ↓
[ABCDE Primario] ← simultáneo con reanimación
       ↓
¿Amenaza vital?
    ├─ SÍ → Corregir → Reevaluar → Secondary Survey
    └─ NO → Secondary Survey
       ↓
Diagnóstico diferencial → Tratamiento específico
       ↓
Estabilización → Alta / Observación / Admitir
```

## 6. Competencias del Médico de Urgencias

| Competencia | Descripción |
|-------------|-------------|
| **Rápidez** | Evaluación en minutos |
| **Síntesis** | Identificar lo crítico sin perderse en detalles |
| **Decisión bajo presión** | Actuar con información incompleta |
| **Comunicación** | Equipo, paciente, familia |
| **Procedimientos** | Vías aéreas, vías venosas, RCP, toracostomía |
| **Diagnóstico** | патrones clínicos, no solo paraclínicos |
