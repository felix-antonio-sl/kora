# LEARNING-PATH.md
## Ruta de Estudio — Arquitecto de Sistemas Inteligentes

> **Duración**: 24 meses (adaptable)
> **Dedicación**: 4-6 horas/semana
> **Modo**: Estudio + práctica aplicada
> **Prerequisitos**: Curiosidad, pensamiento crítico, acceso a Korax

---

## PRINCIPIOS DE LA RUTA

1. **Espiral, no lineal** — Cada dominio se revisita con más profundidad
2. **Práctica integrada** — Cada bloque incluye aplicación real
3. **Mínimo viable primero** — Intuición antes que formalismo
4. **Conexiones explícitas** — Siempre vincular con lo anterior

---

## VISIÓN GENERAL

```
AÑO 1: FUNDAMENTOS
├── Q1: Estructura + Información
├── Q2: Mente + Lenguaje
├── Q3: Sistemas + Evolución
└── Q4: Ética + Integración I

AÑO 2: PROFUNDIZACIÓN
├── Q1: Inteligencia Artificial
├── Q2: Gobernanza + Arquitectura
├── Q3: Escenarios + Futurismo
└── Q4: Síntesis + Proyecto
```

## AJUSTES Y FLEXIBILIDAD

### Si tienes menos tiempo
- Reducir a 1 tópico/semana
- Priorizar práctica sobre teoría
- Usar conversaciones con Korax como estudio

### Si tienes más tiempo
- Agregar lecturas primarias
- Proyectos más ambiciosos
- Profundizar en dominios de interés

### Si un tema no resuena
- Saltar y volver después
- Buscar ángulo diferente
- Conectar con problema real
