# PCA v3.0 + Korax: Guía de Usuario

*Para Korvo — Cómo usar el sistema y qué esperar*

---

## Qué Es Este Sistema

Un **exoesqueleto cognitivo** que protege tu atención, no un sistema de productividad que la consume.

```
┌─────────────────────────────────────────────────┐
│  TÚ decides qué importa                         │
│  KORAX facilita que no se te olvide             │
└─────────────────────────────────────────────────┘
```

**El sistema NO busca que hagas más cosas.**
Busca que hagas **las cosas correctas** con el **costo cognitivo justo**.

---

## Los 4 Principios (memorízalos)

| # | Principio | En la práctica |
|---|-----------|----------------|
| **P1** | La atención es el recurso soberano | Si el sistema consume mucha atención, está fallando |
| **P2** | Separación de captura y triaje | Captura sin pensar, triaje con calma |
| **P3** | Navegación por energía, no algoritmo | "¿Qué puedo hacer AHORA?" no "¿Qué es más urgente?" |
| **P4** | Empieza simple, escala solo si falla | No agregues complejidad preventiva |

## Tu Día a Día

### Durante el Día: Captura

Cuando algo cruza tu mente:

```
/inbox revisar propuesta GORE
/inbox llamar a Juan
/inbox idea para automatizar reportes
```

**Reglas de captura:**
- Sin contextos (@trabajo)
- Sin urgencias (!)
- Sin pensar "¿es importante?"
- <5 segundos y olvídalo

> "Si tarda más de 5 segundos, perdiste el pensamiento."

---

### Noche (21:00): Triaje

Korax te recordará si no lo has hecho.

**El ritual (15-20 min):**

Por cada item en el inbox, decides:

```
1. ¿Basura? → ELIMINAR (sin culpa)
2. ¿Para después de 14 días? → INCUBAR (Someday)
3. ¿Depende de otro? → WAITING (envía el mensaje primero)
4. ¿Para los próximos 14 días? → COMPROMETER
   - Modo: DEEP / SHALLOW / SOCIAL
   - Timebox: 30 / 60 / 90 min
```

**Objetivo:** Inbox vacío al terminar.

**Regla del 50%:** Si eliminas >50% como basura, estás capturando demasiado ruido. Ajusta tu filtro mental (pero en el momento de captura, no antes).

---

### Mañana (5 min): Planificación

1. Mira tu calendario: "¿Qué bloques tengo libres?"
2. Asigna 1-2 compromisos DEEP al bloque más largo
3. El resto no existe hasta mañana

```
Ejemplo de tu día:
- 09:00-11:00: DEEP disponible → "Revisar propuesta GORE" (60min)
- 11:00-12:00: Reunión DIPLADE → SOCIAL (ya calendarizado)
- 14:00-16:00: Fragmentos → SHALLOW batch
```

---

### Los 3 Modos Energéticos

| Modo | Qué es | Cuándo usarlo | Duración |
|------|--------|---------------|----------|
| **DEEP** | Trabajo que construye estado mental complejo | Energía alta + 0 interrupciones | 60-120 min |
| **SHALLOW** | Logística, emails, tareas fragmentables | Entre reuniones, energía media-baja | 15-45 min |
| **SOCIAL** | Coordinación sincrónica con otros | Cuando otros están disponibles | Variable |

**Criticidad simple (3 preguntas):**
1. ¿Tiene deadline externo esta semana?
2. ¿Es compromiso con alguien que importa?
3. ¿Desbloquea otras cosas importantes?

Si ≥2 son SÍ → Es lo primero que va al bloque.

---

### Cada 2 Semanas (Viernes 20:00): Sincronización

Korax preparará un resumen. Juntos responden:

1. **¿Siguen siendo estos mis objetivos?**
   - Revisar compromisos vs metas del trimestre

2. **¿Estoy moviendo piedras grandes o solo grava?**
   - ¿Cuántos DEEP completé en 2 semanas?
   - Si <2 → Problema de protección de tiempo

3. **Bancarrota selectiva**
   - Items >30 días sin movimiento → Eliminar o redefinir
   - Waiting >14 días → Escalar o abandonar

4. **Renegociación**
   - Compromisos que ya no puedo/quiero cumplir
   - Comunicar honestamente

**Duración:** 45-60 min

## Qué Esperar de Korax

### Korax SÍ hace:

| Acción | Cuándo |
|--------|--------|
| Capturar lo que le dictas | `/inbox <texto>` |
| Recordarte el triaje | Si no lo hiciste en >2 días |
| Preparar la sincronización quincenal | Viernes de semanas impares |
| Alertar sobre Waiting estancado | Items >3 días sin respuesta |
| Detectar señales de colapso | Buffer >30, Waiting >8, 0 DEEP |
| Proteger tu Modo Caos | No molestar durante esas 2h |
| Proponer bancarrota | Si el sistema se desborda |

### Korax NO hace:

| Acción | Por qué |
|--------|---------|
| Decidir qué es importante | Eso es tu juicio |
| Sugerir destino en triaje | Evitar sesgo |
| Agregar contextos automáticamente | P2: separación de concerns |
| Calcular prioridades con fórmulas | P3: navegación por energía |
| Activar extensiones sin permiso | P4: simplicidad primero |

> **Invariante:** Korax nunca decide por ti. Observa, sugiere, facilita, alerta.

## El Modo Caos (Obligatorio)

**Mínimo 2 horas por semana sin estructura.**

- No capturas
- No triajes
- No time-boxes
- Leer, caminar, explorar, divagar

Korax te recordará si llegas a 0 horas en la semana.

> "La estructura debe servir a la vida, no al revés. Sin esto, el sistema se vuelve prisión."

## Señales de que Funciona

| Señal | Qué significa |
|-------|---------------|
| Inbox vacío al menos 3 de 5 días | Triaje funcionando |
| ≥2 bloques DEEP por semana | Tiempo profundo protegido |
| <10% del tiempo en el sistema | No es un parásito |
| Waiting <5 items | Dependencias bajo control |
| Puedes decir qué harás mañana | Claridad mental |

---

## Señales de que Falla

| Señal | Diagnóstico | Solución |
|-------|-------------|----------|
| Buffer >50 items | Triaje insuficiente o captura de basura | Bancarrota: borrar todo >7 días |
| No respeto mis bloques | Optimismo en planificación | Reducir carga al 50% |
| Sensación de robotización | Sistema demasiado rígido | Más Modo Caos |
| Todo parece urgente | Sin criterio de criticidad | Aplicar las 3 preguntas honestamente |
| Sistema consume >10% tiempo | Demasiada complejidad | Simplificar, volver al core |

---

## Cuándo Korax Interviene Solo

### Abandono detectado

| Días sin triaje | Korax dice |
|-----------------|------------|
| 3 días | "¿Todo bien? Hay X items esperando" |
| 7 días | "¿Triaje rápido o bancarrota selectiva?" |
| 14 días | "¿Pausamos el sistema o hablamos?" |

### Colapso detectado (≥3 señales)

- Buffer >30 y creciendo
- Waiting >8 items
- 0 bloques DEEP en 2 semanas
- >50% items "alta criticidad"
- >3 mensajes después de 23:00

Korax propondrá **Modo Emergencia**:
1. Bancarrota asistida
2. 48h de gracia (solo urgente-urgente)
3. Reconstrucción gradual

## Resumen en 30 Segundos

1. **Captura** sin pensar (`/inbox texto`)
2. **Triaje** cada noche (15-20 min, inbox vacío)
3. **Planifica** cada mañana (5 min, 1-2 items DEEP)
4. **Sincroniza** cada 2 semanas (45-60 min, bancarrota selectiva)
5. **Modo Caos** 2h/semana (obligatorio)

Korax recuerda, alerta, facilita. Tú decides.
