# HODOM HSC — Contexto operativo (derivación salubrista-hah, 2026-03-25)

## Resumen
Félix asume como Director Técnico + médico regulador de HODOM (Hospitalización Domiciliaria) del Hospital de San Carlos, Servicio de Salud Ñuble. Primera reunión de equipo inminente (26 marzo 2026).

## Situación
- HODOM existe desde 2023, resultados históricos sólidos (>2.100 pacientes, 0 fallecidos no esperados)
- Opera bajo su potencial: brechas de formalización, trazabilidad, regulación clínica, coordinación, tecnología
- Hospital con deterioro grave de oportunidad de hospitalización (96,8% → 40,6%)

## Estrategia 3 Horizontes
1. **H1:** Optimizar con recursos actuales. Reducir carga cognitiva, no aumentarla.
2. **H2:** Cumplimiento normativo (DS 1/2022, Norma Técnica 2024, protocolos, indicadores)
3. **H3:** Máxima expresión con tecnología, IA, automatización, gestión del conocimiento

## Principio rector
Ordenar sin rigidizar, formalizar sin burocratizar, mejorar sin sobrecargar, más claridad y menos fricción.

## Narrativa política
Diplomática: reconocer logros → mostrar estado actual con honestidad → ordenar brechas → proponer evolución realista. Sin culpabilizar.

## Brechas prioritarias (ahora ya)
- Regulación clínica / revisión de casos
- Escalamiento clínico
- Registro clínico mínimo homogéneo
- Formulario ingreso + evaluación domicilio/cuidador
- Briefing/tablero diario

## Prototipos web prioritarios
- Panel/tablero operativo
- Registro web móvil de atención
- Módulo regulación clínica
- Georreferenciación y rutas
- Alta / contrarreferencia

## Problemas operativos reales
- Tiempos muertos, profesionales esperando, baja productividad médica
- Media jornada médica inestable
- Paradigma presencial dominante
- Coordinación informal, poca alternancia clínica entre médicos
- Altas poco reguladas

## Rol médico redefinido
No solo visitas presenciales → también regulación clínica, revisión de casos, seguimiento remoto, apoyo a terreno.

## Activos a reactivar
- Sueroterapia (reinstalar)
- Oxigenoterapia (3 concentradores subutilizados)
- Enlace HODOM-APS (Programa Postrados) como embrión de continuidad
