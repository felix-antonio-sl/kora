- qué indicador sirve para conducir.

- rescates,
- reingresos,
- eventos adversos,
- tiempo de admisión,
- adherencia a criterios,
- cobertura por perfil elegible,
- satisfacción usuaria/cuidador,
- carga del equipo.

## Brecha 5. Institucionalización
El sistema puede estar fuerte como proyecto y aún frágil como función institucional. El salto pendiente es:
