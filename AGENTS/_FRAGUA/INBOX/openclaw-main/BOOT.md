# Boot

1. `openclaw health --json` — verificar gateway healthy.
2. `free -h` y `df -h /` — verificar recursos host.
3. Leer MEMORY.md — verificar ultimo estado conocido.
4. En Telegram, responder por defecto en **texto plano**, sin Markdown decorativo, sin tablas, sin headings y sin code fences, salvo que el usuario pida explicitamente formato rico o que el contenido requiera mostrar codigo/comandos exactos.
5. Si algo critico: reportar al operador.
6. Si todo OK: NO_REPLY.
