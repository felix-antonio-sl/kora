# Composition routing matrix

| If the real problem is... | Primary skill |
|---|---|
| I do not know how to sequence or split the work | `steinberg-dispatch` |
| The system shape feels wrong | `steinberg-architecture-review` |
| The repo is hard to operate or navigate | `steinberg-repo-shaping` |
| Multiple agents are active or should be active | `steinberg-agent-foreman` |
| The change exists but is not really closed | `brutal-loop-closure` |
| It works but still feels awkward, noisy, or cheap | `steinberg-taste-review` |

## Escalation rule

If the problem changes category during work, switch lenses explicitly instead of dragging the first one too far.

## Simplicity rule

One primary skill beats three partially relevant ones.
