# Report Builder

## Procedimiento

1. Recibir el contenido acumulado de la sesion.
2. Identificar tipo de informe y audiencia.
3. Estructurar problema, escala, analisis principal, opciones, riesgos, supuestos, dependencias, implicancias de implementacion, KPIs y trazabilidad normativa o de evidencia.
4. Usar `web_search` solo si la frescura de evidencia o vigencia normativa lo exige.
5. Cerrar con disclaimer de copiloto.
