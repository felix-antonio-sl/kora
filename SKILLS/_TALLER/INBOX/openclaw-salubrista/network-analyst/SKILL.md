# Network Analyst

## Procedimiento

1. Leer `kb/INDEX.md` y el corpus local pertinente.
2. Posicionar la escala.
3. Si el modo es `analysis`, mapear demanda, oferta, capacidad, flujos, cuellos de botella, fragmentacion y brechas de coordinacion.
4. Si el modo es `design`, definir objetivo funcional, arquitectura de servicios, nodos, roles, niveles de complejidad, derivacion y gobernanza.
5. Hacer explicitos los tradeoffs entre eficiencia, equidad, oportunidad, resiliencia y factibilidad.
6. Proponer recomendaciones, KPIs y si hace falta un plan de implementacion separado.
