# Implementation Planner

## Procedimiento

1. Leer `kb/INDEX.md` y el corpus local necesario.
2. Definir objetivo operativo y criterio de exito.
3. Evaluar factibilidad: capacidad, restricciones, dependencias, madurez del equipo y timing.
4. Identificar sponsor, responsables y nodos de coordinacion.
5. Estructurar fases: preparacion, piloto, escalamiento y estabilizacion.
6. Definir gestion del cambio.
7. Identificar riesgos y mitigaciones.
8. Definir indicadores de proceso, resultado y seguridad.
9. Cerrar con logica de avanzar, mantener, corregir o rollback.
