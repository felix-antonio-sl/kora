An initial state of an object B is a state at which B is upon its generation or as the system starts executing. A final state of an object B is a state from which B cannot exit. A default state of an object B is the state which B is expected to be when its state is not specified. Value is a state of an attribute, therefore it is a specialization of state. In addition to being at some state, an object can also be unstable, when it is in transition between two states—the input state and the output state. State transition is an unstable period of time for an object, which takes place when a process acts on it to change its state.
