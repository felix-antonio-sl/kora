Of course, all these objects are physical, so they are shaded. This is the time to learn about a simple kind of link between objects, the aggregation-participation link. The name of this link describes what it does: it connects between one object, which is the aggregate - or the whole, and other objects, which are the participants, or parts of the whole. An aggregation-participation link doesn't not link objects with processes. This means that in OPM, an object cannot be composed of processes, Similarly, processes cannot be composed of objects. Now, let's start connecting the objects: first, let's connect Car Chassis to Charging Module Pile. An aggregation-participation link is represented by a line with a black triangle along it. Great! Car Chassis is now connected to Charging Module Pile with an aggregation-participation link. Let's connect the rest of the objects.
