# 2026-04-28

## Cambio principal

- `agent-skill-construction-spec` quedo como norma vigente para construir
  agentes y skills antes de transmutar.
- El gate ejecutable incorpora checks `construction-*`, incluido
  `construction-authoring-shape`.
- El lenguaje de canario se retiro de construccion; queda como verificacion
  runtime general cuando aplique.

## Decisiones operativas

- Construccion: `Req -> Blueprint -> IR`.
- Fuente primaria: `AGENT.md` o `SKILL.md` con `artefacto` conforme a
  `autoria-spec`.
- Runtime: siempre derivado desde IR; `_BUILD/` no es autoridad.
- Staging puede contener insumos antiguos, pero no se promociona sin absorcion
  a `autoria-spec`.
- `v2-agentfile` normaliza a `vector_ontologico/presentacion`; no debe escribir
  `harness_vector/presentation`.
